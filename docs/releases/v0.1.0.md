# v0.1.0

## Overview

The repository has progressed beyond the original foundation-only scope. The current implementation includes working discovery, ZTE monitoring, event/alert processing, Discord/Telegram notifications, and an integrated command runtime.

## Highlights

- ICMP/ARP discovery, orchestration, and hostname resolution
- ZTE H3601P authenticated collection and presence tracking
- Typed events, alert rules, bounded alert history, and provider isolation
- Discord webhook and Telegram outbound notifications
- Authorized Telegram commands and Discord native slash commands
- Shared runtime state and platform-specific command UI

## Architecture

The implemented architecture is a single Python runtime composed of discovery, `DeviceRegistry`, `PresenceTracker`, `EventBus`, `AlertEngine`, `AlertHistory`, `NotificationManager`, and `CommandService`. Dashboard, REST API, database persistence, and packaged Docker/K3s deployment remain future work.

## Repository Organization

- `docs/` contains current architecture, discovery, monitoring, command, deployment, and troubleshooting documentation.
- `services/` contains discovery, alerting, and command implementations.
- `scripts/` contains the installed CLI and diagnostics.
- `tests/` contains mocked unit and integration tests.

## Next Candidates

Persistence, a REST API/dashboard, metrics export, and production deployment packaging are future work.
