# v0.1.0

## Overview

Milestone v0.1 establishes the foundation of Sentinel as a self-hosted monitoring platform. This release focuses on repository structure, documentation, diagram assets, and release-oriented project scaffolding.

## Highlights

- Repository structure for future development
- Architecture documentation and diagrams
- Deployment and monitoring documentation scaffolding
- GitHub project housekeeping
- Release notes and contributor guidance

## Architecture

The documented architecture defines Sentinel as a modular, self-hosted monitoring platform composed of a dashboard, REST API, discovery service, monitoring service, alert engine, notification service, and database, deployed on Docker Compose or K3s.

## Repository Organization

The repository is organized around documentation, deployment, service boundaries, and release assets:

- `docs/` for architecture, deployment, API, monitoring, and troubleshooting material
- `diagrams/` for editable Draw.io sources
- `docs/images/` for exported SVG and PNG diagrams
- `.github/` for repository templates and contributor workflows
- `infrastructure/`, `services/`, `configs/`, `scripts/`, `tests/`, and `examples/` for future implementation work

## What's Next

The next milestone is v0.2 Device Discovery. That milestone will begin implementation work while keeping the existing architecture and documentation as the reference point.
