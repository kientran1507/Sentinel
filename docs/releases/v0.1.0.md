# Version 0.1.0

[Package metadata](../../setup.cfg) declares version `0.1.0`. That value alone does not establish a tagged, published, or deployment-verified release; this page does not certify a historical release artifact.

The current source includes ARP/ICMP discovery, optional hostname enrichment, ZTE monitoring, typed events/alerts, Discord/Telegram integrations, SQL inventory/history, and historical commands.

For current implementation boundaries and PostgreSQL verification results, use [project status](../PROJECT_STATUS.md). REST API/dashboard, metrics export, and packaged Docker/K3s deployments remain future work. See [roadmap](../development/roadmap.md).
